# Support

## Getting Help

### Documentation

- Browse the pattern files in each category folder
- Each pattern includes detailed explanations and three language implementations
- Check the [README](README.md) for an overview and quick navigation

### Questions

- **GitHub Issues**: For bugs or pattern-specific questions
- **GitHub Discussions**: For general questions and pattern discussions

### Common Issues

#### Code doesn't compile

- Make sure you're using the correct language version:
  - **Swift**: 5.9+
  - **Dart**: 3.0+
  - **TypeScript**: 5.0+
- Check that you've included all necessary imports

#### Pattern seems incorrect

- Open an issue with the pattern name and your concern
- Include references to support your argument
- We'll review and update if needed

### Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines on how to contribute new patterns or fix existing ones.
